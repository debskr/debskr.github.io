Feature Projects

Here are a few of my featured projects. Each project showcases my ability to deliver high-quality, interactive, and engaging experiences.

Visualearn

Meet VisuaLearn: The Infinite AI-Powered Learning Platform for Visual Learners 🚀 As a developer and designer, my brain is hardwired for visuals. Reading dry tutorials rarely clicks for me. That’s why I built VisuaLearn. A platform that makes technical learning purely visual. Instead of hardcoded tutorials, the AI generates custom lessons on the fly: through diagrams, real-life analogies, and code walkthroughs.

SnapNShare

SnapNShare is a web application that helps users to print on demand during an event. User can connect to the app using a QR code and upload their photos. The app will then edit and customize the image with custom stickers, filters and photoframe and print the photos on demand. I have used javascript and python. The entire system has been developed using Agentic IDE.

Realtime_RaffleDraw

Realtime Raffle Draw is an echosystem of applications that make digital raffle draw system more robust for events. The app features an admin panel, that manages the draw system, participant management and prize management. There is a frontend, for showing the qr code for users to connect, shows countdown and winners name along with win prize. There is a participant frontend, where users can connect using the qr code and enter their details to participate in the draw. I have used node server and socket.io for real-time communication. The entire system has been developed using Agentic IDE.

Imagen

Imagen is a standalone python based app that lets users to generate images using diffusion model API. User can generate images by providing text prompts and the app will generate images based on the prompts. I have implemented features like Auto generate, which generate images automatically, Prompt management, where favorite prompts can be stored, select image resolution, and a huge image based templates that influence and guide prompts visually for specific image result.

IELTS MockTest

IELTS MockTest is a web application that helps users to prepare for the IELTS Speaking exam. User will be able to take the standard mock test as per the IELTS guideline by speaking directly to the model. The app will ask questions based on the IELTS guideline and based on the users spoken level, the app will finally provide a band score and feedback based on the users performance. I have used LLM API to support the app to generate accurate Question sets, used web speech API that interacts with user through voiceover.

HomeDoc

Homedoc is a chat based application that helps users to get quick answers to their heal their desease through home remedies. User only needs to include the symptoms and the AI will provide a list of possible diseases and the treatment plan. I have used LLM API to support the app to generate accurate treatment procedures and remedies based on the user's input. Implemented and managed the api calls, created detailed system prompt and manage reference to create ai replies in context.

Healthify

Healthify is an application that helps users to calculate their BMI and BMR level and provide their daily food habit and exercise routine and the AI will provide a customized diet plan and exercise routine to help them achieve their fitness goals. I have used LLM API that help to generate the customized diet plan and exercise routine based on the user's input.

Booklens AI

Booklens AI is an All in one application that automates youtube content creation journey. User only needs to include the topic name only and the app will automate the entire process to get ai generated storyboard with youtube script, captions, seo tags, thumbnails, voiceover script and also with scene by scene image with video prompt for converting each scene images to video. It is capable to reduce 80 percent youtube content creation hardles. I have used LLM and diffusion model API to support the app to generate contents, Implemented and managed the api calls, created detailed system prompt and manage reference to create character consistency throughout scenes.

AI News Explorer

AI news app is a source of showing Latest AI based applications, tools, and innovations. It current ai tech advancements, it is really difficult to track down and get informations quickly, AI news app is the single platform that indexes latest innovations on different AI and lists them for better search and get quick reviews. I have searched all the newses and indexed all the data using json, vibe coded the entire application to utilize and manage the data
